# Web Technology Lab

This repository contains the assignments completed for the Web Technology
Lab course. Each assignment lives in its own folder, with its own setup
instructions and README where relevant.

## Assignments

| # | Folder | Description | Tech Stack |
|---|--------|-------------|------------|
| 1 | [`icl-website`](./icl-website) | A multi-page university website built with React, demonstrating components, props, JSX, `useState`, event handling, React Router, and responsive CSS. | React, Vite, React Router |

## Getting Started

Each folder is a self-contained project. To run any of them:

```bash
cd <folder-name>
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173`).

## Notes

- No backend, database, or authentication is used in any of these
  projects — they are frontend-only lab exercises.
- More assignments will be added to this repository as the course
  progresses.
